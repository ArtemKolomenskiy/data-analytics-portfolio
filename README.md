# Портфолио проектов

В этом репозитории я собрал портфолио из нескольких кейсов, с которыми столкнулся в рамках профессиональной деятельности. Каждый проект — дашборд для конкретного бизнес-заказчика, решающий его реальные задачи. Цель проектов — показать мой подход: от постановки проблемы и проектирования витрины данных до построения сводных таблиц и визуализаций.

## Проекты

| Проект | Задача |
| --- | --- |
| [Лицензии контрагентов](01-licenses-contractors/README.md) | Контроль сроков окончания лицензий на программные продукты компании. |
| [Заработные платы отдела продаж](02-sales-salaries/README.md) | Автоматический расчёт ежемесячных премий менеджеров и ежеквартальных премий руководителей по фактическим платежам. |
| [План-фактный анализ продаж](03-sales-plan-fact/README.md) | Сравнение плана и факта продаж по месяцам, выявление отклонений по руководителям, сотрудникам и продуктам. |

Все проекты построены на синтетических данных, сгенерированных специально для демонстрации. В профессиональной деятельности я работал с PostgreSQL, ClickHouse и BI-системой LuxmsBI, а витрины данных строил с помощью SQL-запросов. В портфолио я воспроизвёл те же подходы и логику на синтетических данных с помощью Python, pandas и HTML/CSS.

В каждой папке находятся исходный ноутбук со всеми этапами и готовый HTML-дашборд. HTML-файл можно скачать и открыть в браузере без запуска Python.
